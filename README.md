# Платформа M&K

CRM для управления лидами, офферами, командами и партнёрскими выплатами.

В первой версии реализованы:

- интерактивный дашборд и детализация KPI;
- лиды, статусы, источники, проблемы и карточка клиента;
- несколько банковских офферов на одного лида;
- выплаты, стоимость целевого действия и чистый доход;
- пользователи, команды, рейтинги и журнал сессий;
- аналитика по дням, часам, продуктам и источникам;
- ключи доступа, ограничения времени и центр интеграций;
- партнёрский кабинет с уровнями Bronze / Silver / Gold / Platinum.

Структурированные данные рассчитаны на Cloudflare D1. Схема находится в
`db/schema.ts`, миграции — в `drizzle/`.
